\section{The Semantic Engine: Large Language Models}
\label{ch:background_llm}

In the previous chapter, we established how the Options framework allows our lumberjack and miner to execute discrete macro-actions, such as \texttt{COLLECT\_WOOD} or \texttt{BUILD\_BRIDGE}. However, MARL agents cannot inherently deduce the logical sequence of these macro-actions. This chapter introduces the theoretical foundations of Large Language Models (LLMs) and their optimization mechanisms. It establishes how these autoregressive models can act as a high-level "Commander," parsing the semantic state of the grid-world and issuing the correct strategic sequence to the agents below.

% ──────────────────────────────────────────────────────────────────────────
\subsection{Foundations of Causal Language Modeling}
\label{sec:llm_foundations}

Unlike standard reinforcement learning policies that output continuous spatial coordinates, LLMs operate over massive discrete vocabularies (often exceeding $100,000$ unique tokens, representing words or sub-words). These models rely entirely on the Transformer architecture, which dispenses with temporal recurrence in favor of parallelizable self-attention mechanisms~\parencite{Vaswani_Shazeer_Parmar_Uszkoreit_Jones_Gomez_Kaiser_Polosukhin_2017}.

To understand this conceptually, imagine our Commander receives a text prompt: \emph{"Agent 1 has Wood and Stone. It should go to the Workbench and craft a..."} As illustrated in Figure~\ref{fig:clm_autoregressive}, to accurately predict the next word ("Pickaxe"), the network must understand the relationship between "Wood", "Stone", and "Workbench" despite the distance between these words in the sentence.

The core computational engine that achieves this is Scaled Dot-Product Attention. For a given input sequence, the model embeds the tokens into three distinct weight matrices: Queries ($Q$), Keys ($K$), and Values ($V$)~\parencite{Vaswani_Shazeer_Parmar_Uszkoreit_Jones_Gomez_Kaiser_Polosukhin_2017}. 
\begin{itemize}[nosep]
    \item \textbf{Query ($Q$):} What the current token is looking for (e.g., the word "craft" sends a query searching for materials).
    \item \textbf{Key ($K$):} What previous tokens contain (e.g., "Wood" and "Stone" hold keys identifying them as materials).
    \item \textbf{Value ($V$):} The actual semantic content extracted if the Query and Key match.
\end{itemize}

The attention mechanism computes a weighted sum of these values, where the weight is determined by the dot-product similarity of the query and the key:
\begin{equation}
\label{eq:self_attention}
    \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V
\end{equation}
where $d_k$ is the dimension of the key vectors, utilized as a scaling factor to prevent vanishing gradients. In Causal Language Modeling (CLM), a strict lower-triangular mask is applied to the $Q K^T$ matrix. This mathematically prevents the model from "looking into the future," ensuring that the prediction for token $i$ can only attend to tokens that occurred before it.

The \emph{softmax} function is a mathematical operation that converts a vector of raw, unbounded scores (logits) into a normalized probability distribution, ensuring all values fall between 0 and 1 and sum to exactly 1. In Equation~\ref{eq:self_attention}, it translates the dot-product similarities into valid attention weights. Later, at the very end of the network, a final softmax layer converts the model's output logits into the probability $P(y_i)$ of the next token over the entire vocabulary.

The generation process behaves like a strict deterministic time-loop: the model predicts a single word, and that new word instantly becomes part of the unchangeable past context used to predict the very next word. Given a context sequence $X$ and a target sequence of tokens $\mathbf{y} = (y_1, y_2, \dots, y_N)$, the network is optimized by minimizing the negative log-likelihood (Categorical Cross-Entropy) over the sequence~\parencite{Radford_Narasimhan_Salimans_Sutskever_2018}:
\begin{equation}
\label{eq:clm_loss}
    L_{\text{CLM}} = -\frac{1}{N} \sum_{i=1}^{N} \log P(y_i \mid y_{<i}, X; \Theta)
\end{equation}
where $\Theta$ represents the parameters of the neural network. As visualized by the backward gradient flow in Figure~\ref{fig:clm_autoregressive}, the predicted probability distribution is compared to the target token using this loss. It penalizes the model when the probability assigned to the correct target token $y^*_i$ is too low, and gradients ($\nabla_\Theta$) are backpropagated to update the model weights.

This foundational pre-training over trillions of words endows LLMs with vast latent world models, encompassing logical dependencies, domain knowledge, and common-sense heuristics.

\subsection{Parameter-Efficient Fine-Tuning (QLoRA)}
\label{sec:qlora}

While a base LLM understands general logic, it does not inherently know how to output perfectly formatted JSON commands for our specific MARL environment. Teaching it these specific rules via full parameter fine-tuning requires massive GPU clusters, rendering it infeasible for local execution alongside a MARL training loop. 

To mitigate this, this thesis utilizes Quantized Low-Rank Adaptation (QLoRA)~\parencite{Dettmers_Pagnoni_Holtzman_Zettlemoyer_2023}. Conceptually, imagine the base LLM is a massive, immutable public library of knowledge. Rather than rewriting every book in the library, QLoRA simply slips a highly specialized, lightweight guidebook into the building that tells the model exactly how to format its thoughts for our grid-world.

Mathematically, instead of updating the full pre-trained weight matrix $W_0 \in \mathbb{R}^{d \times k}$, QLoRA freezes $W_0$ using 4-bit NormalFloat quantization. As illustrated in Figure~\ref{fig:lora_architecture}, it then injects two trainable, low-rank adapter matrices $A \in \mathbb{R}^{r \times k}$ and $B \in \mathbb{R}^{d \times r}$, where the rank $r \ll \min(d, k)$~\parencite{Hu_Shen_Wallis_Allen-Zhu_Li_Wang_Wang_Chen_2021}.

To ensure that the untrained adapters do not inject noise into the network at the beginning of training, matrix $A$ is initialized with random Gaussian values, while matrix $B$ is initialized as a zero matrix. As a result, the initial product $BA = 0$. The modified forward pass is defined as:
\begin{equation}
\label{eq:lora_forward}
    h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} (B A) x
\end{equation}
where $\alpha$ is a constant scaling factor utilized to modulate the magnitude of the adapter activations~\parencite{Hu_Shen_Wallis_Allen-Zhu_Li_Wang_Wang_Chen_2021}. 

The computational efficiency of this architecture is realized exclusively during backpropagation. When the loss $L_{\text{CLM}}$ is calculated, gradients for the frozen matrix $W_0$ are discarded. The optimizer exclusively calculates and applies updates to the dense, low-dimensional adapter matrices $A$ and $B$. To achieve the memory constraints required for local execution, this thesis employs \emph{QLoRA} (Quantized LoRA)~\parencite{Dettmers_Pagnoni_Holtzman_Zettlemoyer_2023}. QLoRA aggressively quantizes the frozen base weights $W_0$ down to a 4-bit NormalFloat (NF4) representation. Combined, this targeted gradient flow and aggressive quantization reduce overall VRAM consumption by up to 75\% compared to full fine-tuning, enabling our Commander to run efficiently alongside the MARL training loop.

\subsection{The Qwen Architecture and Agentic Capabilities}
\label{sec:qwen_architecture}

To serve as the cognitive controller in a MARL system, the chosen foundation model must possess advanced coding, reasoning, and instruction-following capabilities. This thesis leverages the Qwen model family, specifically utilizing the Qwen 2.5 7B parameters architecture, representing state-of-the-art open-weights performance~\parencite{Yang_Li_Yang_Zhang_Hui_Zheng_Yu_Gao_Huang_Lv_et_al._2025}.

A key innovation in the Qwen architecture is the inherent integration of a ``thinking mode'' for complex, multi-step reasoning alongside a non-thinking mode for rapid, context-driven responses~\parencite{Yang_Li_Yang_Zhang_Hui_Zheng_Yu_Gao_Huang_Lv_et_al._2025}. In the context of reinforcement learning, this duality is critical. The Commander model can rapidly parse structured JSON inputs representing the lumberjack's inventory, while simultaneously allocating internal computational resources to process multi-step dependency paths (e.g., verifying that a Pickaxe must be crafted before Iron can be mined). By coupling the Qwen architecture with QLoRA, the model can be locally fine-tuned to act as a highly specialized, latency-bound orchestrator.

\subsection{Neuro-Symbolic Orchestration and Verbal Reflection}
\label{sec:llm_rl_integration}

As established in section~\ref{sec:abstraction_shaping}, pure deep reinforcement learning struggles with severe exploration bottlenecks in sparse-reward environments. While the Options Framework offers a mathematical solution to temporal abstraction, designing the rules for when to trigger an Option traditionally demands extensive human engineering. 

Because LLMs develop powerful logic and reasoning skills during their initial pre-training, they can be deployed as \emph{zero-shot}\footnote{In machine learning, "zero-shot" refers to a model's ability to successfully perform a task it was not explicitly trained for, relying purely on generalized knowledge acquired during pre-training.} semantic orchestrators. This means the model can manage complex tasks right out of the box, completely bypassing the need for human engineers to write manual, hard-coded decision rules. Frameworks such as ReAct~\parencite{Yao_Zhao_Yu_Du_Shafran_Narasimhan_Cao_2023} have shown that interleaving language reasoning with concrete actions allows models to solve multi-step problems autonomously. In reinforcement learning, systems like EUREKA~\parencite{ma2024eurekahumanlevelrewarddesign} and PRM4RL~\parencite{Zhang_Gao_Jiang_Chen_Pan_Zhang_Deng_2025} successfully use LLMs to automatically write and refine reward functions.

As illustrated in Figure~\ref{fig:neuro_symbolic_hierarchy}, this thesis adopts a strict division of labor known as a Neuro-Symbolic Hierarchy. The high-level LLM Meta-Controller analyzes the environment and dictates strategic goals (e.g., "Craft a Pickaxe") by reasoning over a semantic Directed Acyclic Graph (DAG) of task dependencies. These text-based decisions are translated into discrete Options and passed down to the low-level MAPPO execution workers, which handle the high-frequency kinetic control (e.g., navigating the grid and avoiding obstacles).

However, the low-level agents may sometimes fail to achieve the assigned goal. To solve this, language agents can leverage \emph{Verbal Reflection}~\parencite{Shinn_Cassano_Berman_Gopinath_Narasimhan_Yao_2023} to evaluate and correct execution failures. As detailed in Figure~\ref{fig:verbal_reflection}, if the Commander issues a \texttt{MINE\_IRON} option but the miner stagnates and fails to complete it after 150 steps, the environment halts. A reflection prompt containing the failure context is sent back to the LLM. This forces the model to explicitly diagnose its mistake (e.g., realizing it forgot to assign \texttt{CRAFT\_PICKAXE} first) and issue a corrected macro-action.
